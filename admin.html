Connect to GitHub

Your token stays in this browser. Without it, nobody can change your site.

How do I get a token?
  1. Open GitHub token settings.
  2. Choose “Only select repositories” and pick your website repository.
  3. Under Repository permissions, set Contents to “Read and write”.
  4. Generate the token and paste it above.
